# История версий TOORU · DRAGON

## 0.0.3 — 2026-09-30

Наблюдаемая Тоору.

- Умные уведомления с категориями: важное, завершено, ошибка, требуется решение.
- Непрочитанные уведомления одного события группируются, одинаковые дубликаты не записываются повторно.
- Поручения из чата распознаются и связываются с очередью задач Дракончика.
- Задача хранит источник сообщения, короткий план и флаг необходимости решения.
- Задачи с флагом «требуется решение» не запускаются фоновым execute-режимом.
- Добавлен Дневник Дракончика по дням: действия, обучение и продвижение целей.
- Центр Дракончика получил живую наблюдаемую панель, счётчики событий и прямые ссылки из чата.
- SQLite schema: **11**.

## 0.0.2 — 2026-09-30

Единый дизайн и UX.

- Личный кабинет получил персональную hero-сводку, метрики и быстрые переходы.
- Настройки разделены на «Интерфейс / AI / Версии».
- Система обновления получила отдельный центр состояния, авто-проверку, карточки ревизий, файлов, backup и истории.
- Глобальные сообщения переведены в компактные transient-toast уведомления.
- Popup Дракончика больше не появляется повторно после автозакрытия в одной сессии браузера.
- Унифицированы карточки, статусы, кнопки, радиусы, тени и адаптивные раскладки.

## 0.0.1 — 2026-09-30

Первый системно пронумерованный релиз.

- Ядро: единый источник версии из `VERSION`.
- Интерфейс: защита от старого кеша через хэш CSS/JS и проверку версии клиент ↔ сервер.
- Интерфейс: исправлены CSP-конфликты inline-style и неопределённая CSS-переменная `--border`.
- Интерфейс: устранены повторяющиеся HTML-id в объединённом разделе данных.
- Дракончик Тоору: центр разделён на «Обзор / Задачи / Проект / Права», фоновые обновления больше не перерисовывают всю страницу.
- Обновления: версия и состав релиза видны прямо в интерфейсе.
- Мозг/Дракончик: сохраняются функции релиза schema v10 — Разум v2, автообучение, очередь задач и режимы автономности.

Схема SQLite: **10**.

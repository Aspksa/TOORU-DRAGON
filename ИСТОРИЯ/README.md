# ИСТОРИЯ TOORU · DRAGON

Этот каталог позволяет продолжить разработку в новом чате без повторного объяснения проекта.

- **PROJECT.json** — машиночитаемый снимок требований, решений, состояния и ближайших задач. UTF-8, JSON, ключи на английском, содержание на русском.
- **EVENTS.jsonl** — события по порядку: каждый непустой ряд является отдельным JSON-объектом.
- **PORTABLE.md** — запуск с другого диска, флешки или внешнего SSD.
- **../AGENTS.md** — инструкции для следующего помощника при работе с репозиторием.

История составлена по доступному обсуждению TOORU · DRAGON и проверенному коду. Это структурированная передача контекста, а не дословный экспорт всех сообщений или архив недоступных предыдущих чатов. Планы явно отделены от реализованных функций. Чужие проекты и посторонняя личная переписка не включены.

## Сообщение для нового чата

> Продолжи разработку TOORU · DRAGON: https://github.com/Aspksa/TOORU-DRAGON . Сначала прочитай AGENTS.md, ИСТОРИЯ/PROJECT.json и ИСТОРИЯ/EVENTS.jsonl в актуальной ветке main. Сверь историю с кодом и результатами проверок. Сохрани утверждённые требования, затем выполни мою следующую задачу.

Новый чат должен иметь доступ к репозиторию. Если чтение GitHub недоступно, прикрепите ZIP проекта или файлы истории. Эти файлы не подключают память между чатами автоматически: помощнику нужно их прочитать.

## Обновление истории

Меняйте снимок PROJECT.json и добавляйте запись в конец EVENTS.jsonl в том же изменении, что и код. `code_baseline_commit` обозначает последний проверенный коммит перед текущим изменением; собственный хеш коммита хранить внутри этого же коммита невозможно. Сведения о результатах CI храните с точным коммитом и ссылкой. Не удаляйте прежние решения без события об их пересмотре.

# Запуск с другого носителя

Поддерживаемый вариант: распакованная папка проекта на доступном для записи локальном HDD, SSD, внешнем SSD или USB-флешке, подключённых к Windows 10/11 x64. Буква диска и имя папки могут меняться. Пути с пробелами и кириллицей поддерживаются.

1. Полностью распакуйте ZIP проекта на выбранный носитель.
2. Запустите `StartTooruDragon.bat` из папки проекта. При первом запуске нужен интернет для установки Python в `python/`.
3. Интерфейс откроется в браузере этого компьютера. База будет в `data/` рядом с программой.
4. Перед переносом остановите сервер через Ctrl+C в окне запуска.
5. Скопируйте **всю папку**, включая `python/` и `data/`, на другой носитель или компьютер с поддерживаемой Windows.
6. На новом месте снова запустите `StartTooruDragon.bat`. После установленного Python повторная загрузка для текущего каркаса не нужна.

Обновление исходников отдельно от переноса: сохраняйте свои папки `data/` и `python/`. Не копируйте данные поверх работающей базы. Копия базы в `data/backups` защищает только SQLite; для полного переноса нужна вся папка `data`.

## Границы переносимости

- Запуск непосредственно из ZIP, с носителя только для чтения или без права записи не поддерживается.
- Сетевые папки, NAS и папки с активной облачной синхронизацией базы не являются проверенным режимом; перенесите рабочую папку на локальный носитель.
- Windows x64 требуется и на другом компьютере. Этот BAT не запускает программу на Android, macOS или Linux.
- Флешка должна иметь достаточно свободного места; для больших моделей лучше SSD. У FAT32 ограничение одного файла около 4 ГиБ — выбирайте подходящую файловую систему для больших баз и моделей.
- Не выдёргивайте носитель во время работы. Закрытие вкладки браузера не останавливает сервер.
- Авторизация браузера Qwen пока не реализована. Когда она появится, вход может потребоваться заново на другом компьютере.
- Данные хранятся локально в незашифрованном виде. Переносимость не означает защищённость потерянной флешки.

Разработчикам: `ROOT` вычисляется от `app.py`, данные по умолчанию — `ROOT/data`, launcher переходит в собственную папку. Параметр `--data-dir` является явным переопределением: при его использовании переносить указанный каталог нужно отдельно.

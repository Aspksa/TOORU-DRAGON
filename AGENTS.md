# TOORU · DRAGON — инструкции для продолжения разработки

Перед изменениями прочитайте:
1. `ИСТОРИЯ/PROJECT.json` — принятые решения, реализованное, ограничения и план.
2. `ИСТОРИЯ/EVENTS.jsonl` — журнал обсуждения и изменений (один JSON-объект на строку).
3. `ИСТОРИЯ/README.md`, затем актуальные исходники и проверки в GitHub Actions.

История — контекст проекта, а не замена проверки кода. Сравните базовый коммит истории с текущим HEAD. Не выдавайте планы за работающие возможности. При противоречии фактическое поведение проверяйте по исходникам и тестам; новые указания пользователя имеют приоритет.

Обязательные договорённости:
- Русский интерфейс и корректный UTF-8, версия продукта пока `0.0.0`.
- Одно общее ядро. Сохранять утверждённое меню и порядок разделов.
- Основной запуск — `StartTooruDragon.bat`, с автоматическим открытием браузера после готовности сервера.
- Windows 10/11 x64, переносимый Python в `python/`; без системного Python, PowerShell и обязательного Git у пользователя.
- Пути вычислять от расположения проекта. Не привязывать к D:, имени пользователя или текущей рабочей папке.
- SQLite и личные файлы в `data/`; не коммитить базы, cookies, браузерный профиль, токены, логи, модели или резервные копии.
- Не заменять пользовательские данные при установке/обновлении. Изменения схемы — с миграцией и резервной копией.
- Qwen через отдельный профиль браузера пока только запланирован. Не считать сохранение текста обучением весов модели. Не обходить вход, CAPTCHA и ограничения сайта.
- Не добавлять сетевую доступность локального сервера без системы авторизации и явной задачи.

После значимого изменения обновляйте `ИСТОРИЯ/PROJECT.json` и добавляйте событие в `ИСТОРИЯ/EVENTS.jsonl`: что изменилось, что проверено, что осталось. Не переписывайте старые события. Указывайте фактические результаты; недоступные проверки отмечайте как непроведённые. Не помещайте личную переписку вне темы проекта в публичную историю.

Минимальная проверка кода: `python tests/test_core.py` (Windows: `python\python.exe -X utf8 tests\test_core.py`). Проверка истории: `python tests/test_history.py`. Расширяйте проверки только для изменяемого поведения.

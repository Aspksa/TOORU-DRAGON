# TOORU · DRAGON — 0.0.0

Локальная платформа: одно ядро, домашние и рабочие проекты, память Тори.

Для продолжения из другого чата начните с [ИСТОРИИ](ИСТОРИЯ/README.md), [машиночитаемого контекста](ИСТОРИЯ/PROJECT.json) и [AGENTS.md](AGENTS.md). [Инструкция по переносу на другой носитель](ИСТОРИЯ/PORTABLE.md).

## Запуск на Windows

1. Скачайте репозиторий через **Code → Download ZIP** и полностью распакуйте, например в `D:\TOORU-DRAGON`.
2. Дважды нажмите **StartTooruDragon.bat**.
3. При первом запуске автоматически скачивается официальный переносимый Python 3.13.15 x64 (~11 МБ), проверяется SHA-256 и распаковывается в `python`. Нужен интернет. После этого основное приложение работает без интернета.
4. База создаётся автоматически, интерфейс открывается в браузере по локальному адресу (обычно `http://127.0.0.1:8765`).

Системный Python, Git, PowerShell и отдельный сервер БД не нужны. Поддерживаются Windows 10/11 x64 с `curl.exe`, `tar.exe`, `certutil.exe`. Установка не требует прав администратора; папка должна быть доступна для записи. Для отдельной подготовки можно использовать `SETUP.bat`.

Окно запуска остаётся открытым, пока работает сервер. Для остановки нажмите **Ctrl+C** в нём. Закрытие вкладки не останавливает сервер. Повторный запуск открывает уже работающую копию. Если порт занят другой программой, выбирается следующий свободный. Если браузер не открылся, скопируйте адрес из окна запуска.

Папку проекта можно перенести вместе с `python` и `data`, в том числе на другой диск. Перед переносом и отключением SSD остановите сервер. Перенос браузерной авторизации между компьютерами не гарантируется.

## Что работает

- Утверждённое русское меню, светлая/тёмная/системная тема.
- Профиль и настройки с сохранением в SQLite.
- Создание, просмотр и удаление домашних и рабочих проектов.
- Сохранение личных заметок памяти, знаний, тем обучения и пользовательских сообщений.
- Диагностика базы и компонентов, создание согласованной копии SQLite через backup API.
- Локальный сервер, защита запросов токеном и проверкой Host/Origin; база и произвольные файлы не раздаются через HTTP.

## Чего пока нет

ИИ-модель не подключена: Тори пока не генерирует ответы. Сохранение записей не обучает модель. Поиск по смыслу, редактор записей, автоматическое обучение, наблюдение за Qwen и управление браузером — следующие этапы. В интерфейсе они не выдаются за работающие возможности.

Мобильное подключение и синхронизация не реализованы. Сервер слушает только `127.0.0.1`; не открывайте его наружу без будущей системы авторизации. Интерфейс адаптирован к узким экранам.

Автоматический ZIP-обновлятор, проверка релизов и откат ещё не реализованы. Перед ручным обновлением остановите приложение, сделайте копию базы и сохраните всю папку `data`. Не удаляйте и не заменяйте личные данные новым архивом.

## Данные и резервные копии

- `data/tooru.sqlite3` — настройки, проекты, память и записи.
- `data/documents`, `data/models` — зарезервированы для будущих файлов и моделей.
- `data/browser-profile` — зарезервировано для отдельного браузера Тори; сейчас не используется.
- `data/backups` — копии базы, создаваемые кнопкой в «Системе обновления».
- `data/logs/app.log` — журнал приложения.

Копия SQLite не включает документы, модели и профиль браузера. Для полной резервной копии остановите сервер и скопируйте всю папку `data` на другой носитель. Данные этой версии не зашифрованы. В Git исключены `data`, `python`, временные файлы и секреты.

## План Qwen

Отдельный профиль → наблюдение за выбранным диалогом → очередь материалов с источниками → самостоятельные темы → вопросы после передачи управления. Предусмотрены пауза, лимиты и возврат управления пользователю. Ответы Qwen считаются непроверенными материалами. Возможность и условия браузерной автоматизации требуют отдельного прототипа; обход проверок входа не предусмотрен.

## Проверки

`python\python.exe -X utf8 tests\test_core.py` — интеграционные проверки во временной папке: кириллица, сохранение, удаление, копия базы, настройки, защита запросов, повторный запуск. CI повторяет проверки на Windows с тем же переносимым Python. Фактический запуск браузера нужно дополнительно проверить на пользовательском Windows.

Для разработки на Linux/macOS: `python3 app.py --no-browser`. Только стандартная библиотека, сторонние пакеты не требуются. `--data-dir` позволяет использовать отдельный каталог данных для тестов.

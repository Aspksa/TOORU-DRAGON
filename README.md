# TOORU · DRAGON — 0.0.0

Локальная платформа: одно ядро, домашние и рабочие проекты, память и обучение Тори.

Для продолжения из другого чата начните с [ИСТОРИИ](ИСТОРИЯ/README.md), [машиночитаемого контекста](ИСТОРИЯ/PROJECT.json) и [AGENTS.md](AGENTS.md). [Инструкция по переносу на другой носитель](ИСТОРИЯ/PORTABLE.md).

## Запуск на Windows

1. Скачайте репозиторий через **Code → Download ZIP** и полностью распакуйте, например в `D:\TOORU-DRAGON`.
2. Дважды нажмите **StartTooruDragon.bat**.
3. При первом запуске автоматически скачивается официальный переносимый Python 3.13.15 x64, проверяется SHA-256 и распаковывается в `python`.
4. Интерфейс откроется по локальному адресу, обычно `http://127.0.0.1:8765`.

Системный Python, Git, PowerShell, отдельная БД и `pip install openai` не нужны. TOORU использует стандартную библиотеку Python и обращается к Yandex AI Studio напрямую через HTTPS REST API.

## Что работает

- Русский интерфейс, светлая/тёмная/системная тема.
- SQLite для проектов, памяти, знаний, чатов, настроек и очереди обучения.
- Домашние и рабочие проекты.
- Память и база знаний Тори.
- Контролируемый локальный RAG в чате: по текущему вопросу выбираются только релевантные записи Памяти/Знаний, с ограничением количества и размера.
- Диагностика и резервная копия SQLite.
- Локальный HTTP-сервер с проверкой Host/Origin и токеном интерфейса.
- **Yandex AI Studio + Qwen3.6 35B** для автоматических учебных задач.
- Настоящий **Чат с Тори** через ту же облачную модель.
- Отдельная лента **Тори ↔ Qwen**, где видны вопросы, ответы, ошибки и расход токенов.
- Очередь обучения со статусами: в очереди, выполняется, готово, ошибка, зависла, отменена, пропущена.
- Действия **Отменить / Пропустить / Повторить**.
- Автоматическое обнаружение задачи, зависшей более 10 минут.
- Сохранение успешного ответа Qwen в раздел «Знания».
- Учёт входящих и исходящих токенов по каждой выполненной задаче.

## Подключение Yandex AI Studio

Откройте **Tooru/Ai → Обучение**.

По умолчанию используются:

- каталог: `b1gpcfme4j9b9bv37hqb`;
- модель: `qwen3.6-35b-a3b/latest`;
- endpoint: `https://ai.api.cloud.yandex.net/v1/responses`.

Выберите тип авторизации: **API-ключ сервисного аккаунта** или **IAM-токен пользователя**, вставьте секрет, нажмите **Сохранить**, затем **Проверить связь**. Для длительной работы рекомендуется API-ключ сервисного аккаунта; IAM-токен удобен для быстрой проверки и действует ограниченное время.

Ключ:
- не записывается в Git;
- не возвращается веб-интерфейсу после сохранения;
- хранится только в локальной SQLite-базе `data/tooru.sqlite3`.

Важно: база данных этой версии **не зашифрована**. Если кто-то получит доступ к файлу `data/tooru.sqlite3`, он потенциально сможет получить сохранённый API-ключ. Не публикуйте папку `data`.


## Интерфейс Tooru/Ai

- **Чат** — прямой диалог пользователя с Тори. История хранится локально; в модель отправляется только ограниченный недавний контекст этого чата.
- **Память** — факты и предпочтения, которые пользователь сохраняет вручную. Они пока не отправляются в модель автоматически.
- **Знания** — результаты обучения и материалы, добавленные вручную.
- **Обучение** — отдельный диалог Тори с Qwen, управление очередью и режимом обучения.

Настройки Folder ID, модели и API-ключа вынесены из «Обучения» в общий раздел **Настройки**, чтобы рабочий экран обучения не был перегружен техническими параметрами.

## Как работает обучение

1. Добавьте тему и вопрос в очередь — вопрос сразу появляется в ленте как сообщение Тори.
2. Нажмите **Начать**.
3. Фоновый worker TOORU берёт задачи по одной.
4. Запрос отправляется напрямую в Yandex AI Studio Responses API.
5. Успешный ответ появляется в ленте от имени Qwen и сохраняется в «Знания».
6. При ошибке задача получает статус **Ошибка**.
7. Если задача остаётся выполняющейся более 10 минут, она помечается **Зависла**.
8. Для ошибочной, зависшей, отменённой или пропущенной задачи доступно **Повторить**.

**Пауза** не берёт новые задачи. **Стоп** прекращает запуск новых задач. Уже отправленный синхронный HTTPS-запрос нельзя мгновенно оборвать на стороне модели; его результат будет сохранён только если задача всё ещё находится в состоянии выполнения.

## Почему браузерный Qwen-мост удалён

TOORU больше не автоматизирует `chat.qwen.ai`, не нажимает кнопки на сайте и не скрейпит DOM. Старый каталог `browser/qwen-bridge` удалён.

Автоматическое обучение выполняется через официальный API Yandex AI Studio. Это стабильнее, не зависит от верстки сайта и не требует отдельного Chrome-профиля.

## Контекст чата Тори

Во вкладке **Чат** включён переключатель **Память и знания**. Если он включён, TOORU локально ищет совпадающие записи только среди `memory` и `knowledge`, ранжирует их и передаёт модели не более нескольких наиболее релевантных фрагментов в ограниченном объёме. Вся база целиком не отправляется.

Под каждым ответом Тори показываются метки **Использовано**, поэтому видно, какие записи реально были добавлены в контекст. Переключатель можно отключить для конкретного сообщения — тогда локальная Память и Знания в запрос не попадут.

Текущий поиск лексический и полностью локальный. Векторные embeddings и отдельный внешний индекс пока не требуются.


## Контроль расходов AI

TOORU считает расход по фактическим `input_tokens` и `output_tokens`, которые возвращает Yandex AI Studio. В интерфейсе показываются расход за последние 24 часа, за текущий календарный месяц UTC, суммарные токены и месячный лимит.

Для Qwen3.6 35B по умолчанию используются актуальные на момент реализации тарифы: 0,2 ₽ за 1000 входящих токенов и 0,3 ₽ за 1000 исходящих токенов. Эти значения редактируются в **Настройки → Yandex AI Studio**, потому что провайдер может изменить цены.

Месячный лимит по умолчанию — 1000 ₽. Значение 0 отключает блокировку. При достижении лимита:
- новые сообщения в чат Тори блокируются;
- автоматическое обучение переводится в паузу;
- накопленные данные и очередь не удаляются.

Это локальная расчётная оценка по токенам, а не официальный баланс или счёт из Yandex Cloud Billing.


## Мозг Тори

После обычного ответа чат может выполнить короткий отдельный самоанализ. Он не меняет Память и Знания автоматически, а создаёт до трёх предложений:

- **Память** — устойчивый личный факт или предпочтение, явно сказанное пользователем.
- **Знание** — полезный материал из ответа, который стоит сохранить отдельно.
- **Доучиться** — тема или вопрос, который стоит добавить в очередь обучения.

Каждое предложение требует решения пользователя **Принять** или **Отклонить**. Принятое предложение Памяти/Знания создаёт обычную запись; принятое предложение «Доучиться» добавляет вопрос в очередь обучения.

В форме чата есть переключатель **Мозг: предложения**. Его можно отключить для конкретного сообщения. Самоанализ использует дополнительный запрос AI Studio, а его токены включаются в общий учёт расходов.


### Если AI Studio отвечает 401

HTTP 401 означает ошибку аутентификации. Проверьте:
- выбран ли правильный тип авторизации;
- не истёк ли ключ или IAM-токен;
- API-ключ создан ли для сервисного аккаунта AI Studio и имеет ли нужные области действия;
- IAM-токен передаётся как IAM-токен, а не как API-ключ.

TOORU теперь не считает просто сохранённый секрет успешным подключением. До первой успешной проверки статус показывает **Авторизация не проверена**.
